How It Works

Sign in to your work or school Microsoft Teams account using the Device Code Flow. Once authorized, this tool communicates with Microsoft Teams via the Big Tools backend API to pull your live speed dials.

1. Authenticate: Link Teams via Device Code (no password stored in browser).
2. Reorder: Drag & drop or use Up/Down buttons to customize order.
3. Submit: Apply changes to commit the sequential order to Teams.
