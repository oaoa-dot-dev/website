01 // AI Support Runtime Active Platform

L0 Agent

A pre-L1 AI support runtime for MSPs that ingests external ticket queues, executes sandboxed automations, and posts human-gated resolutions back to PSAs.

L0 Agent is a pre-L1 AI support runtime for MSPs. It watches an external ticketing system (starting with UTRACS), pulls new work into a local ticket queue, and runs an agent workflow: classify the request, match skills and scripts, execute automations in sandboxed containers, then draft and post replies back to the PSA.

Operators keep control in the UI—approve script runs when needed, inspect analysis and session history, and bind platform actions to pluggable system scripts so the core agent stays PSA-agnostic. Credentials live on those scripts; L0 stores the local ticket state, agent decisions, and execution trail so every action is auditable end to end.

02 // Unified Helpdesk & Vault Core MSP Stack

UTRACS

Unified Ticket Resolution & Coordination System

An MSP-focused helpdesk platform for managing client tickets, company records, and secure credentials in one place.

UTRACS (Unified Ticket Resolution & Coordination System) is an MSP-focused helpdesk platform for managing client tickets, company records, and secure credentials in one place. Agents work tickets with threaded email correspondence (Microsoft 365 shared mailboxes via Graph API), company vault secrets (including certificate authentication for remote PowerShell), and SLA-aware dispatch boards.

AI agents can join the same workflow over a documented HTTP API—listing tickets and companies, replying, updating status, and requesting approved vault access—so automation stays audited and human-gated where it matters.

Secrets Vault Cert Auth & Remote PowerShell
SLA & Boards SLA-Aware Helpdesk Boards
AI Agent Integration Audited & Human-Gated API
03 // Intelligence Console Self-Hosted

Telegather

A self-hosted Telegram intelligence console that continuously scrapes live traffic, translates messages, and categorizes channels using local LLMs.

Telegather is a self-hosted Telegram intelligence console. It connects one or more Telegram user sessions, joins channels you care about, and continuously scrapes live traffic plus optional full history into a searchable archive.

Incoming messages are translated (native ONNX and/or external providers), categorized with local LLMs (Ollama), and enriched with links, attachments, and relevance signals. A web UI lets you browse channel chat history, filter messages, preview media, track unique t.me channel links you've seen, and manage sessions, workers, and download policy—without relying on Telegram's own client as your research workspace.

In short: monitor Telegram at scale, keep a durable local copy, and turn noisy channel traffic into something you can search, triage, and act on.
